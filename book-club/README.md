# «Между строк» — Telegram Mini App книжного клуба

Русскоязычное приложение для закрытого клуба до 20 человек. React + TypeScript + Vite + Tailwind, React Router, TanStack Query, Dexie, Telegram Mini Apps SDK (`@tma.js/sdk-react`, поддерживаемый преемник `@telegram-apps/sdk-react`), Supabase PostgreSQL/Auth/Edge Functions.

Проект не требует платного домена, VPS или API. Frontend размещается на GitHub Pages, серверные данные и функции — в Supabase Free. Личные данные закрыты от других участников; IndexedDB хранит локальную копию.

## Быстрый запуск

Нужен Node.js 22.12+ (проверялось на Node 24).

```sh
npm ci
npm run dev
```

Откройте адрес Vite. Без `.env` работает настоящая личная библиотека в IndexedDB: книги, издания, прогресс, отзывы, заметки, цитаты, корзина, JSON-экспорт/импорт. Данные не заполнены демонстрационными записями. Разделы клуба явно сообщают о необходимости настройки.

После подтверждённого входа через Telegram профиль и вся личная библиотека синхронизируются между устройствами через Supabase. Личные книги, страницы, оценки, отзывы, заметки, приватные цитаты, избранное и корзина доступны только владельцу через RLS. Публикация в клубе остаётся отдельным действием, выключенным по умолчанию. Это изменение первоначальной модели «только локально» по запросу владельца клуба.

IndexedDB остаётся локальным хранилищем и позволяет редактировать без сети после загрузки интерфейса. Несинхронизированные изменения существуют только на устройстве: не очищайте WebView до подтверждения синхронизации, сохраняйте JSON-резервные копии. Обычный браузер без входа использует отдельную локальную библиотеку. В профиле есть явный перенос прежних локальных книг в свой аккаунт.

## Возможности

- Личные книги: ручной ввод, поиск нескольких изданий Google Books/Open Library, обложки, редактирование всех полей, поиск/статус/сортировка, индивидуальные страницы, оценка пятью звёздами с половинками, отзыв, спойлеры, приватные заметки.
- Единый поиск своих, клубных и интернет-книг; карточка с быстрыми действиями, цитата без повторного выбора книги и компактные счётчики-фильтры: [FRIENDLY_LIBRARY.md](docs/FRIENDLY_LIBRARY.md).
- Короткое меню управления, формы без лишних полей, приглашения и доступ в отдельных окнах, журнал отправок по требованию и общее оформление: [CALM_ADMIN.md](docs/CALM_ADMIN.md).
- Компактный выбор раздела цитат, фильтры с сохранением при возврате, общая очистка поиска, короткие карточки клубных книг и формы для малых экранов: [MOBILE_UX.md](docs/MOBILE_UX.md).
- Быстрая смена статуса с карточки, выбор главных книг галочками и шуточные награды текущего чтения.
- Короткая форма прогресса с главной и личной полки, прямое открытие нужной книги, черновики текста на устройстве и синхронизируемая корзина книг со всем содержимым: [QUICK_LIBRARY.md](docs/QUICK_LIBRARY.md).
- Синхронизация всей личной библиотеки: серверные версии, повтор после сети, удаление на всех устройствах, объединение независимых правок. При несовместимых правках сохраняются обе версии с выбором в профиле.
- Цитаты: редактирование, книга/страница/глава/комментарий, избранное, поиск/фильтр, копирование, корзина, восстановление, окончательное удаление. Очистка через 30 дней при запуске; для ранее опубликованной цитаты сначала подтверждается удаление серверной копии.
- Общий каталог, отдельный клубный статус, несколько главных книг с датами, порядком и историей. Клубные изменения не меняют личные статусы и страницы.
- Заявки: черновик, рассмотрение, одобрение, отклонение с причиной, исправление отклонённой заявки. Одобрение транзакционно, с блокировкой строки и проверкой дубликата.
- Участники: Telegram-аватар, имя, username, описание, жанры, вступление, счётчики публичных данных, вкладки книг, чтения, отзывов и цитат.
- Цитаты и отзывы публикуются по отдельному согласию; прогресс клубных книг виден активным участникам. Серверные разрешения приватности, скрытие спойлеров, лайки. «Сохранить себе» создаёт независимую личную копию цитаты и книги: она синхронизируется между устройствами, входит в JSON-экспорт и остаётся после удаления оригинала, автора или книги из каталога. Лайк сам по себе копию не создаёт.
- Встречи: создание/изменение/отмена, несколько книг, обратный отсчёт, вопросы заранее и общие итоги после встречи. Telegram-уведомления и напоминания за 24 часа через очередь и Supabase Cron.
- JSON-резервирование: проверка схемы, размера, UUID, ссылок и диапазонов; атомарное объединение или полная замена с предупреждением. Импортированные публикации выключаются; глобальные разрешения приватности не включаются из файла автоматически.
- Очередь публичных операций: офлайн, повтор, подтверждение сервера, защита от дубликатов и запоздавших отправок, видимые ошибки. Личные данные продолжают сохраняться без сети, если приложение уже загружено. Полная офлайн-загрузка закрытого приложения не обещается.
- Светлая/тёмная тема Telegram, системная тема браузера, safe areas, адаптивная навигация, состояния загрузки и отсутствия данных.
- Короткая главная: текущие книги клуба со ссылками и ближайшая встреча. Каталог: «Читаем» с раскрывающимся прогрессом всех участников и «Все книги» с поиском и фильтрами. Вкладки «Прочитано / Не прочитано / Все» с количеством; счётчики личной коллекции. В карточке книги — популярные цитаты, впечатления и средняя оценка; можно дополнить историю давно прочитанной книги.
- Цитаты разделены на свои, сохранённые, понравившиеся, общую ленту и корзину. Поиск по книгам, даты, лайки и отдельная галочка публикации. Пустые страницы без выдуманных данных.

Для уже работающего проекта: [пошаговое обновление](docs/UPDATE.md). Миграцию 001 повторно запускать не нужно.

Голосования за будущие книги, приглашения по ссылке без ID, удаление/восстановление участников, приглашения в Telegram и поиск книг: [COMMUNITY.md](docs/COMMUNITY.md).

Встречи администратора без ответов о посещении, объявления выбранной книги и напоминания за сутки в личный чат с ботом: [MEETINGS.md](docs/MEETINGS.md). Во внутренних карточках и формах есть стрелка назад; системная кнопка Telegram скрыта.

Упрощённая форма книги, текстовые цитаты, быстрые статусы и награды: [SIMPLE_CLUB.md](docs/SIMPLE_CLUB.md).

Вопросы и итоги встреч, разделы библиотеки, главы, рейтинг и история чтения: [CLUB_MEMORY.md](docs/CLUB_MEMORY.md).

Подсказки книг в цитатах, личные обложки с устройства и из интернета, пятизвёздные оценки и возврат: [READER_UI.md](docs/READER_UI.md).

## Команды проверки

```sh
npm run typecheck
npm test
npm run check:edge
npm run build
npx playwright install chromium
npm run test:e2e
```

`npm test` запускает Vitest, React Testing Library и реальное выполнение миграции/политик в PostgreSQL WASM (PGlite) с ролями anon/authenticated и реалистичными default grants. Docker для этого не нужен. PGlite проверяет SQL, ограничения, транзакции и RLS, но не заменяет интеграционную проверку GoTrue, PostgREST, Edge Runtime и Telegram в вашем тестовом проекте.

`npm run check:edge` проверяет TypeScript Edge Functions против установленных типов Supabase и деклараций Deno. Дополнительно на обычной машине/в CI:

```sh
npx deno check --node-modules-dir=none supabase/functions/telegram-auth/index.ts supabase/functions/club-api/index.ts supabase/functions/notifications/index.ts
```

Полный результат локальных проверок и ограничения окружения: [VALIDATION.md](docs/VALIDATION.md).

## Границы бесплатной инфраструктуры

GitHub Pages обслуживает статические файлы, серверная обработка выполняется в Supabase. На бесплатном GitHub обычно нужен публичный репозиторий: код и адрес сайта доступны всем, данные клуба закрывает серверная авторизация.

Supabase Free может приостановить малоактивный проект; квоты и условия могут изменяться. Cron и Edge Functions не выполняются в остановленном проекте. Google Books/Open Library могут ограничивать запросы или не находить издание — ручной ввод остаётся доступен. Напоминания — best effort: возможны задержки, пропуски при недоступности инфраструктуры и редкие повторные сообщения после неопределённого результата Telegram API.

Подробности модели доступа и синхронизации: [ARCHITECTURE.md](docs/ARCHITECTURE.md).
