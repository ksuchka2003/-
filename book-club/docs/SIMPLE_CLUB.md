# Простая библиотека

Для добавления книги достаточно названия. Поиск по названию и автору обращается к бесплатным Google Books и Open Library; выбранный результат заполняет метаданные и обложку. Все русские книги не гарантируются каталогами: при отсутствии совпадения остаётся ручное добавление. У Google Books возможны ограничения запросов, второй источник работает независимо.

В пользовательских формах нет ISBN и поля HTTPS-ссылки. Старые идентификаторы изданий остаются внутри данных для совместимости резервных копий и поиска дубликатов. Обложку можно выбрать из интернет-поиска или загрузить с устройства; она сохраняется только в личном издании. Каталог не меняется от личной картинки.

В «Моих книгах» нажмите кнопку статуса на карточке. Откроются четыре статуса без полной формы. «Прочитано» устанавливает все страницы и дату завершения, другие статусы сохраняют прогресс; отзывы, заметки, главы и настройки публикации не меняются. Изменения работают без сети и синхронизируются обычной очередью.

Цитата добавляется текстом с подсказкой личных и клубных книг. Фото, камера и распознавание удалены; тяжёлые OCR-модели не входят в сборку. Прежние тексты цитат сохраняются.

В «Клуб → Читаем» нажатие на книгу раскрывает всех действующих участников, главу, страницы и процент. Нажатие на человека открывает только опубликованные им цитаты и мысли к этой книге. Приватные заметки не публикуются. Прогресс клубных книг доступен клубу независимо от прежнего publishProgress; остальные публикации — по отдельному согласию.

Администратор ищет книгу по названию или автору. Во вкладке «Главные книги» выбирает нужные галочками; одна транзакция меняет клубный статус и активное чтение. Несколько выбранных книг поддерживаются. Даты и порядок остаются дополнительной настройкой. Снятие галочки снимает книгу с главной, сохраняет историю и возвращает текущий статус в «Запланировано»; чтобы отметить фактическое завершение клубом, выберите статус в карточке редактирования.

На экране загрузки — рассказ о клубе из Санкт-Петербурга. Искусственной задержки нет: после авторизации открывается главная, личная синхронизация продолжается в фоне. Формы и списки проверяются на мобильных экранах, длинные названия переносятся, поля ограничены шириной контейнера.

## Шуточные награды

Для каждой текущей клубной книги 🥇 получает первый синхронизированный финиш, 💩 — последний, только когда книгу закончили все активные участники и их не меньше двух. Значки видны в прогрессе клуба, списке и профилях участников. Награды подтверждаются сервером, до синхронизации не показываются.

Сервер фиксирует время перехода личного статуса в «Прочитано». Редактирование обложки или заметки не двигает финиш; клиентская дата завершения не определяет порядок. Офлайн-финиш учитывается в момент получения сервером. Исправление статуса отзывает финиш, повторное завершение получает новое время. Книга, снятая с текущего чтения, больше не показывает награды. Новый цикл чтения начинает их заново; старые прочтения и старые даты не назначают победителей автоматически. При нескольких текущих книгах награды независимы.

Личная библиотека хранится в Supabase с доступом только владельцу и локальной копией IndexedDB. Уведомления — в личном боте: [MEETINGS.md](MEETINGS.md).

Если русское название не находится, дополнительный поиск использует языковую ссылку Википедии и повторяет запрос по оригинальному названию в Open Library. Для статьи о книге можно получить название и доступную обложку через Wikimedia API; биография автора не используется как книга. Текст статьи целиком не копируется. Источники API: [Open Library Search](https://openlibrary.org/dev/docs/api/search), [MediaWiki Langlinks](https://www.mediawiki.org/wiki/API:Langlinks), [PageImages](https://www.mediawiki.org/wiki/Extension:PageImages).
