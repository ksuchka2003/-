# Поиск книг для цитат, обложки и оценки

В новой цитате достаточно начать вводить название. Подсказки ищут по личной библиотеке и каталогу клуба, показывая автора и источник. Выбор книги клуба создаёт связанную личную книгу только при сохранении цитаты. Если она уже есть у читателя, используется существующая запись. Точное введённое название также проверяется на совпадение; одноимённые книги разных авторов требуют выбора в подсказках. Если совпадений нет, можно оставить собственное название.

Поиск цитат находится над вкладками и ищет название книги и текст. Отдельный список выбора книги удалён. «Сохранено себе» содержит независимые личные копии, «Мои лайки» — текущие публикации с вашей реакцией. Звёздочка избранного остаётся личной отметкой. Оригинал может исчезнуть из лайков после удаления автором; сохранённая копия остаётся.

## Личная обложка

«Мои книги → книга → Изменить обложку» позволяет выбрать изображение из галереи. Оно обрабатывается локально, сохраняется как JPEG до 60 000 символов data URL в необязательном `Book.coverData`, затем синхронизируется в закрытой библиотеке владельца. Исходный файл не загружается. Данные обложки входят в JSON-экспорт/импорт. Старые резервные копии совместимы.

Обложка клубной личной книги видна рядом с прогрессом её владельца и на его личной полке. Это указано в форме до сохранения. Общая обложка каталога не меняется. «Вернуть обложку книги» удаляет личную замену; можно также редактировать HTTPS-ссылку в данных издания. Для книг без связи с каталогом личная обложка остаётся только в закрытой библиотеке.

Миграция 007 дополняет серверную проекцию `visible_progress.cover`, допускает ограниченный JPEG data URL или HTTPS-адрес. Неверные значения отбрасываются. При обновлении общей обложки проекция обновляется для читателей без личной замены. Права на таблицы не расширяются; изображения не дают доступа к заметкам, отзывам или остальной библиотеке.

Общие обложки могут относиться к разным изданиям и языкам. Источники: [Open Library Search](https://openlibrary.org/dev/docs/api/search), [Covers API](https://openlibrary.org/dev/docs/api/covers), [АСТ — «Елтышевы»](https://ast.ru/book/eltyshevy-865558/). Администратор меняет общую картинку в каталоге; читатель выбирает свою в личной книге.

## Пять звёзд

Оценка показывается пятью звёздами с половинным шагом. Прежняя шкала 1–10 сохранена в данных: 9 баллов = 4½ звезды, 8 = 4 звезды. Существующие оценки, средний рейтинг и JSON не пересчитываются и не теряются. Нажатие на левую/правую половину звезды выбирает половинную/целую оценку. С клавиатуры доступны стрелки, Home/End и удаление оценки; есть отдельная кнопка «Убрать оценку».

## Возврат

В формах и модальных окнах стрелка сверху закрывает текущий экран. Во внутренних карточках книги, участника и панели администратора она возвращает к предыдущему маршруту приложения; для прямой ссылки есть безопасный переход к родительскому разделу. Главные семь разделов не имеют лишней стрелки. В каталоге вкладка, поиск и фильтр хранятся в URL, поэтому возвращение из книги их восстанавливает. Системная кнопка Telegram остаётся скрытой: используется стрелка приложения.
