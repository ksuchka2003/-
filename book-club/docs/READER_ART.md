# Иллюстрации без повторов и лёгкий декор

12 ноября 2026 года. Добавлены предоставленные пользователем изображения без изменения пикселей и прозрачности. Первый лист уже совпадал с `src/assets/illustrations/readers-atlas.png`, поэтому второй экземпляр не создаётся. Второй лист сохранён как `src/assets/illustrations/club-life-atlas.png`. Изображения обслуживаются вместе с приложением, внешние сервисы не нужны.

Каждый из восьми сюжетов имеет одно место в интерфейсе:

| Сюжет                     | Место            |
| ------------------------- | ---------------- |
| Читательница с книгой     | Главная          |
| Кофе и ноутбук            | Мой профиль      |
| Разговор за столом вдвоём | Заголовок встреч |
| Читательница в наушниках  | Мои книги        |
| Книги с собой             | Каталог клуба    |
| Записи за столом          | Цитаты           |
| Обсуждение втроём         | Участники        |
| Настольная игра           | Меню «Ещё»       |

Сюжеты выделяются CSS из исходных прозрачных листов. Повторы из пустых состояний, каждой встречи и боковой панели удалены. В пустых состояниях остаётся небольшая иконка книги и понятный текст. Декорации скрыты от скринридера, не принимают нажатия и не заменяют пользовательские аватары.

Полноширинные разделители в списках, профиле, меню и переключателях заменены отступами. Сохранены границы полей ввода, обозначение выбранной вкладки, шкалы прогресса и видимый клавиатурный фокус. К существующему бумажному оформлению добавлены маленькие книжные марки, веточки у отдельных обложек и уголки страниц. Градиенты, тени и скругления не возвращаются.

Серверные функции, данные и права не меняются. Для обновления достаточно публикации frontend.
