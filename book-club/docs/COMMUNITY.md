# Хранение, приглашения и группа Telegram

Личная библиотека, прогресс, отзывы, заметки, цитаты и настройки аккаунта сохраняются на сервере в `private_library_records` с доступом только владельцу. IndexedDB содержит локальную рабочую копию. При входе сначала выполняется согласование с сервером; офлайн-изменения отправляются после восстановления соединения. Конфликты сохраняют обе версии. Неподтверждённая отправка не отображается как успешная синхронизация. Локальный режим без входа остаётся отдельным и не синхронизируется.

Каталог, участники, встречи и доступные публикации также кешируются в IndexedDB текущего аккаунта после серверной проверки доступа. При доступной сети используются актуальные серверные данные; при сетевой ошибке доступна ранее полученная копия. Офлайн-доступ не создаёт новую сессию Telegram. Загруженный ранее интерфейс продолжает работать без сети.

## Обновление базы

После миграций 001 и 002 выполните **один раз** `supabase/migrations/202610310003_polls_and_invites.sql`. Она добавляет голосования, защищённые приглашения и представления администратора. Исходную 001 повторять не нужно. Затем разверните `telegram-auth`, `club-api` и `telegram-bot`; настройки `notifications` не меняются.

## Приглашение без Telegram ID

В **Управление → Доступ** создайте ссылку для одного человека либо для группы. Ссылка действует 7 дней и допускает выбранное число новых участников. В базе хранится только SHA-256 хеш случайного токена. Можно отозвать ссылку до окончания срока.

Участник открывает ссылку, нажимает Start в боте и кнопку приложения. Сервер проверяет Telegram initData, затем атомарно погашает приглашение. Роль всегда `member`; общий предел — 20 активных участников. Повторный вход того же участника не расходует приглашение. Удаление участника закрывает доступ и профиль, сохраняя его личную библиотеку. Удалённый участник не сможет вернуться по старой или новой общей ссылке: администратор должен нажать «Восстановить» рядом с его именем.

## Голосование

Отправка предложения автоматически открывает голосование во вкладке **Клуб → Будем читать**. Черновики не публикуются. Доступны «Хочу читать», «Позже», «Не хочу»; повторное нажатие снимает голос. Один человек имеет один изменяемый голос. Участники видят общий результат и свой выбор. Администратор видит итоги при рассмотрении заявки, может закрыть опрос и принимает окончательное решение. Одобрение или отклонение закрывает голосование. Опрос работает внутри приложения и не отправляет массовые сообщения в группу.

## Подключение бота к группе

Серверный webhook `telegram-bot` защищён `TELEGRAM_WEBHOOK_SECRET`. Он отвечает только на `/start` и `/club`, а не импортирует историю группы и не получает список всех её участников.

Добавьте серверные секреты:

- `TELEGRAM_APP_URL` — HTTPS-адрес приложения на GitHub Pages.
- `TELEGRAM_WEBHOOK_SECRET` — случайная строка из 32 байт в hex (64 символа), без публикации во frontend.

После развёртывания установите Bot API `setWebhook` на `https://PROJECT_REF.supabase.co/functions/v1/telegram-bot`, передав тот же `secret_token` и `allowed_updates: ["message"]`. Для автоматической настройки предусмотрен POST `{ "install": true }` на эту функцию с заголовком `x-telegram-bot-api-secret-token`. Этот вызов доступен только владельцу серверного секрета. Он откажется перезаписывать webhook другого приложения и не удалит ожидающие обновления.

В **Управление → Доступ → Клуб в Telegram-группе** получите ссылку и выберите группу в Telegram. Команда `/club` покажет кнопку клуба. Если у бота включён Main Mini App в BotFather, ссылка открывает приложение сразу; иначе она ведёт в личный чат бота с кнопкой Mini App. Кнопки Bot API типа `web_app` предназначены для личного чата, поэтому для группы используется обычная ссылка. Боту достаточно разрешения отвечать на команды; права администратора для этой функции не нужны. Не отключайте privacy mode ради `/club`.

Для прямой ссылки на приложение настройте в **BotFather → /mybots → бот → Bot Settings → Configure Mini App** основной Mini App с URL GitHub Pages. Названия пунктов могут зависеть от версии BotFather. Ссылку можно закрепить в группе вручную. Добавление бота в группу не делает всех её участников членами закрытого клуба: используйте приглашения.

## Поиск книг и ISBN

Вошедшие участники ищут через `club-api`, что устраняет зависимость от CORS браузера. Используются Google Books и Open Library с таймаутами, кешем и резервным источником. ISBN очищается от дефисов, пробелов и префикса; кириллическая `Х` заменяется на латинскую `X`, проверяется контрольная цифра. ISBN ищется как идентификатор, без ограничения языка.

Каталоги не гарантируют наличие каждого российского издания. Ошибка квоты отличается от отсутствия совпадений; ручной ввод доступен всегда. `536700198Х` нормализуется в корректный `536700198X`, однако при проверке 31 октября 2026 года Open Library не вернула издание, а Google Books без ключа ответил HTTP 429. Не следует подставлять вымышленные данные. При желании можно добавить собственный бесплатный `GOOGLE_BOOKS_API_KEY` в серверные Secrets; он не нужен для работы остальных функций и Open Library, не попадает в frontend и не требует платной подписки. Лимиты Google зависят от проекта.
